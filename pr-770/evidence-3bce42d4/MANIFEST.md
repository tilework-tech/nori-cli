## Machine

Modal x86-64 Linux session, kernel 7.3.4 (`Linux-7.3.4-x86_64-with-glibc2.36` in each file's `platform`/`runner` field), tmux 3.3a, 120×40 draining pane, loopback, warm binary pages, fresh home per sample.

## Fixtures

All data is synthetic, generated by `fixture.py`, `agent.py` and `startup_agent.py` in this directory.

- 4 sections: 43 ACP updates, 741 bytes of message text.
- 64 sections: 643 ACP updates, 11,042 bytes of text, about 258 KB persisted transcript.
- 32 sections for the wire check (`transport.json`): 323 ACP updates.
